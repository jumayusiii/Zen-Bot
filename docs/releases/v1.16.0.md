# Zen v1.16.0

**Released:** 2026-10-30 · **Status:** public beta

Zen now has friendly social actions, a fuller moderation toolkit and a dedicated Images tab.

## Added

- **Social actions** — `/hug`, `/pat` and `/highfive` target a member with a randomly chosen line and a compact embed.
- **Warnings** — `/warn` records a per-server warning, DMs the member when possible and writes to `/modlog`. `/warnings` lists the history privately, and `/clearwarnings` removes it with an audit entry.
- **Bulk cleanup** — `/purge` scans up to 100 recent messages, supports a member filter and skips messages older than Discord's 14-day bulk-delete limit.
- **Slowmode** — `/slowmode` sets a channel cooldown from 0 seconds to 6 hours, with a permission check and an audit entry.
- **Images** — `/cat` and `/dog` fetch random photos without API keys, while `/memegen` accepts a template and editable top and bottom text across six templates.
- The command directory now covers **70 commands** across eight tabs, including the new **Images** tab.

## Data and permissions

- Warning history lives in `data/warnings.json`, scoped per server and retained across restarts.
- `/warn` needs **Moderate Members**; `/warnings` is private to moderators; `/clearwarnings` needs **Manage Server**.
- `/purge` needs **Manage Messages** in the channel, plus **Read Message History** for the bot.
- `/slowmode` needs **Manage Channels** for the member and the bot.
- Image commands need outbound HTTPS access to `api.thecatapi.com`, `dog.ceo` and `api.memegen.link`; no API keys are required.

## Install or upgrade

```bash
npm ci
npm run deploy
npm run deploy:global
npm start
```

No new npm dependencies or Discord intents are required.
