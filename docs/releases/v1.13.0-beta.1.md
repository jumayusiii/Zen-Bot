# Zen v1.13.0-beta.1

**Released:** 2026-10-30 · **Status:** public beta

Four new commands add quick conversation starters, fortune cookies, a growing memory game and a timed typing race.

## Added

- **`/topic [theme]`** — starts a conversation with an icebreaker, hypothetical, nostalgia, creative or food prompt, with a one-click shuffle.
- **`/fortunecookie`** — opens a fortune with a theme and six lucky numbers, with another-cookie control.
- **`/memory`** — shows a symbol sequence, hides it, then scores your repeat. Every completed round adds one symbol.
- **`/typerace`** — opens a Discord modal, times an exact phrase and reports words per minute with a speed rating.
- The command directory now covers **57 commands** across seven tabs.

## Improved

- Modal submissions now route through the shared interaction handler, so commands can use real text inputs.
- `/typerace` and `/memory` are locked to the player who started the round, like the other minigames.
- Fortune, topic, memory and typing-race selection and scoring are covered by the test suite.

## Install or upgrade

```bash
npm ci
npm run deploy:global
npm start
```

With `GUILD_ID` set, `npm run deploy` updates that server immediately. Without it, commands register globally and can take up to an hour to appear.

No new environment variables, dependencies or Discord intents are required.
