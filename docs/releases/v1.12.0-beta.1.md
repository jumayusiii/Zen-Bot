# Zen v1.12.0-beta.1

**Released:** 2026-10-29 · **Status:** public beta

Weather and Wikipedia join the command directory, and TikTok previews get a creator avatar.

## Added

- **`/weather <location> [units]`** — current conditions plus a four-day forecast from [Open-Meteo](https://open-meteo.com/). Supports Celsius and Fahrenheit, and needs no API key.
- **`/wikipedia <query>`** — searches Wikipedia, posts a summary with the article image, and links to the full page.
- The command directory now covers **53 commands** across seven tabs.

## Improved

- `/tiktok` embeds show the creator avatar as a thumbnail.
- The default install URL requests the `bot` and `applications.commands` scopes with the permissions Zen needs.
- `README.md` and the directory submission copy describe the new commands.

## Install or upgrade

```bash
npm ci
npm run deploy
npm start
```

With `GUILD_ID` set, commands update in that server immediately. Without it, they register globally. Re-run `npm run deploy` after this update so `/weather` and `/wikipedia` appear.

No new environment variables are required. The bot needs outbound HTTPS access to Open-Meteo and Wikipedia.
