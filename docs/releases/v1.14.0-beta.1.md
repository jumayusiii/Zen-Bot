# Zen v1.14.0-beta.1

**Released:** 2026-10-30 · **Status:** public beta

The Zen profile now has a wide banner that matches the avatar, and Type Race remembers the fastest time each member has set.

## Added

- **Zen banner** — a 1500×600 profile banner built from the same open ensō ring, cream Z, ink field and mint/jade palette as the avatar.
- **`/typeraceleaderboard`** — shows the ten fastest Type Race times in the server, plus your personal best and rank.
- **Personal bests** — every correct `/typerace` run is compared with that member's record and saved only when it is faster.
- The command directory now covers **58 commands** across seven tabs.

## Improved

- `/typerace` result cards report a new personal best or your existing record.
- Type Race bests persist in `data/typerace.json` and survive restarts; in-progress races still reset with the process.
- The banner assets ship as a vector master and 1500×600 and 750×300 PNG exports.

## Install or upgrade

```bash
npm ci
npm run deploy:global
npm start
```

No new dependencies, environment variables or Discord intents are required.
