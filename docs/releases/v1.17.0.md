# Zen v1.17.0

**Released:** 2026-10-30 · **Status:** public beta

Zen’s Social tab now connects to live public social media, with no API keys needed.

## Added

- **Bluesky** — `/bluesky <handle>` loads a live profile, bio, follower counts and the latest public post, with **Open profile** and **View latest post** buttons.
- **Reddit** — `/reddit [subreddit]` reads Reddit’s public Atom feed and posts a random hot item from a curated SFW community, with the post link and source subreddit.
- **YouTube** — `/youtube <url>` resolves standard, Shorts and `youtu.be` links into a live title, channel, thumbnail and **Watch on YouTube** button.
- The command directory now covers **73 commands** across eight tabs.

## Feed notes

- Bluesky uses the public AppView API at `public.api.bsky.app`.
- Reddit uses `www.reddit.com` Atom feeds because Reddit’s public JSON endpoint is frequently blocked. The command is limited to a curated SFW list; NSFW communities are rejected.
- YouTube uses the public oEmbed endpoint at `www.youtube.com/oembed`, so private or removed videos fall back to a clear error.
- These commands need outbound HTTPS access only. They need no API keys, OAuth tokens or new npm dependencies.
- `/hug`, `/pat` and `/highfive` remain available as local social actions alongside the live feeds.

## Install or upgrade

```bash
npm ci
npm run deploy
npm run deploy:global
npm start
```

No new Discord intents are required. Refresh Discord with `Ctrl+R` after deployment to see the three new commands.
