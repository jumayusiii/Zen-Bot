# Zen v1.11.0-beta.2

**Released:** 2026-10-29 · **Status:** public beta

The bot formerly known as Juma Habbo is now **Zen**.

## Changed

- The display name, documentation, startup examples, directory copy and `/changelog` now use **Zen**.
- The application ID `1564936469305364480` and the command set are unchanged, so existing installs, permissions and stored data keep working.
- TikTok requests identify as **ZenBot** in their user agent.
- The package version is `1.11.0-beta.2`.

## Install or upgrade

Existing installs need no re-invite. To update a self-hosted copy:

```bash
npm ci
npm run deploy
npm start
```

No new environment variables are required. The GitHub repository and the Discord Bot List URL keep their existing `juma-habbo` slugs; only the display name changes.
