# Zen v1.15.0-beta.1

**Released:** 2026-10-30 · **Status:** public beta

Zen can now answer questions with OpenAI’s ChatGPT through a moderated, rate-limited beta command.

## Added

- **`/chatgpt <prompt> [private]`** — sends one prompt to OpenAI and posts the answer in a branded embed. The optional `private` flag keeps the answer visible only to the requester.
- **Moderation first** — prompts are checked with `omni-moderation-latest` before generation.
- **Per-user limits** — each member can make **8 requests per 10 minutes**. Answers show the remaining allowance for that window.
- **Bounded answers** — prompts are capped at 2,000 characters and responses at 700 output tokens. Long answers are marked when the output limit cuts them off.
- The command directory now covers **59 commands** across seven tabs.

## Privacy

- Zen does not store ChatGPT prompts, answers or conversation history.
- Requests use the Responses API with `store: false`. OpenAI’s abuse-monitoring and data-control policies still apply to requests sent to its API.
- The API key stays on the bot host in `OPENAI_API_KEY` and is never sent to Discord or exposed to users.

## Configuration

Add an OpenAI key to `.env` and restart:

```dotenv
OPENAI_API_KEY=your-key
OPENAI_MODEL=gpt-6-luna
```

`OPENAI_MODEL` is optional; it defaults to `gpt-6-luna`. The command is registered even without a key, but replies with setup instructions until one is added. Keys are server-side only.

## Install or upgrade

```bash
npm ci
npm run deploy:global
npm start
```

No new npm dependencies or Discord intents are required. The bot needs outbound HTTPS access to `api.openai.com` for `/chatgpt`.
