# Zen brand mark

The Zen mark pairs an open ensō ring with a bold Z: calm, continuous and still readable at Discord's smallest avatar sizes.

| File | Use |
| --- | --- |
| `zen-avatar.svg` | Master vector; edit this file |
| `zen-avatar-1024.png` | High-resolution bot avatar and app icon |
| `zen-avatar-512.png` | Standard Discord upload size |

## Palette

| Role | Hex |
| --- | --- |
| Ink | `#0A111D` |
| Deep ink | `#101B2C` |
| Mint | `#5EEAD4` |
| Jade | `#2DD4BF` |
| Cream | `#FFFFFF` |
| Ambient violet | `#6D5EFC` |

## Usage

- Keep the gap in the ensō at the upper right; it is part of the mark.
- Keep the Z centered and inside the ring.
- Do not stretch, rotate, outline or recolor the gradients.
- The mark is designed for Discord's circular avatar crop; preserve the existing padding.
- Upload the PNG through the Discord Developer Portal, or use the file directly with the bot avatar API.
