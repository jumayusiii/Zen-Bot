New · Release 1.19.0-beta.13 · 5 November 2026

The latest beta is ready to list

Zen now monitors habbo.si, explains and manages chat XP, and gives admins a safe way to remove coins. The public set is exactly 100 slash commands; the copy below matches this release.

Released 5 Nov 2026
NEW

What changed

  • habbo.si monitoring — /sitestatus and /uptime now use the new site.
  • Level tools — /levelinfo shows XP, rank and the next reward; /leveladmin adds, removes, sets or resets XP.
  • Coin control — /removecoins lets admins and owners remove up to 100,000 coins, stopping at zero.
  • Clearer beta marker — 👷‍♂️ replaces 🧪 across /helplist.
100

Why three commands moved

Discord caps global slash commands at 100. Three overlapping commands were folded into existing ones so the new tools fit:

  • /rankcard → /rank theme:<name>
  • /inventory → /shop
  • /clearwarnings → /warnings clear:true

No feature was removed; only the entry point changed.

**Zen** is a friendly, slash-command-only Discord bot that keeps a community fun,
social and tidy without reading message content.

### Fun and games
- Memes, animal memes, editable memes, cat and dog photos.
- Trivia, tic-tac-toe, blackjack, hangman, Higher or Lower, word scramble, memory,
  slots, reaction tests, number guessing and typing races.
- Live would-you-rather votes, polls, reminders, timestamps and quick decisions.

### Levels and economy
- Chat XP with rendered rank cards, server rank, progress and a top-ten
  leaderboard.
- Ten card themes: Aurora, Sunset, Ocean, Forest, Midnight, Candy, Sakura,
  Cyber, Ember and Frost.
- `/levelinfo` explains the XP rules and next level; admins can use
  `/leveladmin` to add, remove, set or reset XP with an audit log.
- A beta per-server economy with `/daily` streaks, level-up payouts, `/shop` for
  owned and equipped themes, and admin-only `/grantcoins` and `/removecoins`.

### Moderation and community
- Timed mutes, temporary and permanent bans, kicks, soft bans, warnings, purge,
  slowmode, channel locks and unlocks.
- `/warnings clear` removes a member's warnings with an audit entry; `/modlog`
  configures the audit channel.
- `/welcome` and `/leave` with custom templates and test previews.

### Images, social and knowledge
- Live `/bluesky`, `/reddit`, `/youtube` and `/tiktok` lookups.
- `/weather` forecasts from Open-Meteo and `/wikipedia` summaries.
- `/sitestatus` and `/uptime` for website monitoring, TLS, DNS, headers and
  incident history — now watching **habbo.si**.

### Built for clean servers
- 100 slash commands, no prefix and no message-content access.
- The public set stays at Discord's 100-command limit: `/rank theme` replaces
  `/rankcard`, `/shop` replaces `/inventory`, and `/warnings clear` replaces
  `/clearwarnings`.
- Persistent polls, reminders, levels, warnings, greetings, channel locks and
  uptime history.
- Optional beta `/chatgpt`; works only when the owner configures an OpenAI key,
  and Zen does not store prompts.

`/animalmeme`, `/weather Tokyo`, `/wikipedia Jupiter`, `/typerace` or

Registry and feature matrix ↗

Vote webhook rules
  • Read the raw body before JSON parsing.
  • Return 2xx within 5 seconds; queue slow work.
  • Verify top.gg’s HMAC-SHA256 signature over {timestamp}.{rawBody}.
  • Use the configured secret for DBL and botlist.me.
  • Deduplicate by user and vote window.
  • Reward only a verified, first-time vote.
  • Provide an opt-out for vote reminders.
Reality check

Zen does not currently expose an HTTP webhook server. Adding vote rewards is a separate feature — do not expose the Discord token as a webhook secret.

09 · Approval

Rules that get bots declined

These are the highest-value checks from published directory guidelines. Fixing them before submission is faster than appealing a decline.

Read before submitting
01

Offline, private or code-granted

Keep Zen online and invitable for the whole review. Zen’s code grant is already off.

02

Wrong prefix

Zen is /, not a text prefix. Reviewers need to invoke it immediately.

03

Requests Administrator

Not allowed. Zen’s invite uses permissions 1099780180998 and does not include it.

04

No clear entry point

/helplist is the directory. Put it in the listing and the reviewer note.

05

Vote-locking most commands

Keep it to no more than 3–5 commands, or do not vote-lock at all. Zen locks none.

06

Owner commands exposed

No public eval, shell or status command. Admin commands stay permission-gated.

07

Fork or duplicate clone

Do not list the same codebase as multiple bots, or submit someone else’s bot.

08

Keyword-stuffed copy

Use the short description as written. Padding it with tags is a rejection reason.

09

Advertising unrelated things

Do not promote other bot lists, unrelated servers or paid services in the listing.

10

NSFW assets

Keep the name, avatar, banner and description SFW, even if the bot has NSFW commands.

11

Undisclosed DMs

Zen only DMs for warnings and reminder delivery. Disclose it in the privacy policy and offer deletion.

12

Broken links or buttons

Test every invite, support link, privacy link and button after saving the listing.

Three declines for the same reason can block you. Fix the issue before resubmitting. If a listing is declined and the reason is unclear, use the directory’s staff ticket flow instead of opening a second submission.

12 · Public policy

Privacy policy

Use this page as Zen’s public privacy URL. It describes what the bot stores, what it never reads, and how to request deletion.

Effective 2 Nov 2026

This policy explains how Zen (“the bot”, “we”) handles data when you add it to a Discord server or use its commands. Questions and deletion requests go to GitHub Issues.

Data Zen stores

Zen stores only what its features need. Depending on the features a server uses, this can include:

  • Discord server, channel and user IDs, plus display names.
  • XP, levels, coin balances, owned card themes and inventory items.
  • Warnings, moderation settings, audit-log channel IDs and temporary-ban state.
  • Polls, reminders, greeting templates and channel-lock restore state.
  • Uptime samples, Type Race bests and role-reward settings.

What Zen does not read

Zen does not read or store message content. It uses the Server Members intent only to support welcome and leave events. Moderation commands use Discord’s own permission and role-hierarchy checks.

ChatGPT beta

/chatgpt sends the prompt you write to OpenAI only when you use that command. Zen does not store prompts or conversation history. The command is optional and only works when the bot owner configures an OpenAI API key.

Storage and security

Feature data is stored in local JSON files on the bot owner’s host. Discord and API tokens are kept in a server-side environment file, never in the repository or browser. Data is retained while the relevant feature remains configured.

Third parties

Zen connects to Discord’s API and, for specific commands, to public services such as Open-Meteo, Wikipedia, meme and image providers, and social media feeds. Those services receive only the request needed to answer the command. OpenAI is used only for /chatgpt, as described above.

Deletion and your rights

To delete a server’s data, the bot owner can remove the relevant JSON file in data/; removing the whole data/ directory resets every feature. To request deletion or ask what is stored about you, open an issue at github.com/jumayusiii/Zen-Bot/issues. We will respond as quickly as possible.

Children and changes

Zen is not directed at children under 13. If this policy changes, the effective date at the top of this section will change. Continued use after an update means you accept the revised policy.

Effective 2 November 2026 · Zen 1.19.0-beta.13
